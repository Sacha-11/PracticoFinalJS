# PracticoFinalJS

Juego del dinosaurio desarrollado con HTML, CSS y JavaScript.

## Cómo jugar

Abre `index.html` en un navegador. Presiona la barra espaciadora para saltar y evitar los cactus. Usa **Reiniciar juego** para comenzar una partida nueva en cualquier momento.

## Características

- El dinosaurio cambia de color mientras salta.
- La velocidad aumenta cada 100 puntos.
- El puntaje máximo se guarda en el navegador.
- Hay efectos de sonido al saltar y al alcanzar múltiplos de 100 puntos.
